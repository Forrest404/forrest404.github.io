Making a Blog

29 Oct

I decided to start code my own website to write down my thoughts, ideas and talk about what im building.

The site is plain HTML and one CSS file. There is no framework, no build step and no JavaScript, so every page loads fast and I can read all of it. It is hosted on GitHub Pages, so publishing is just a git push.

Writing a note is meant to be easy too. I write a short text file with a title, a description and the note itself, then run one script. It makes the page and adds it to the notes list, the home page, the RSS feed and the sitemap, so I never have to edit those by hand.

What goes here is mostly build notes. What I changed, what broke, and what I learned fixing it. I mostly write them so I remember later, but if they help someone else that is a bonus. If you use a feed reader, the RSS feed will tell you when there is a new one.
